# Pilates Atlas — Whole-site acceptance criteria

This is the canonical scope for the whole site. Photo verification is one separate measure; it is never the whole-site completion percentage.

## Learning architecture
- English first, Korean alongside; one canonical site and stable URLs.
- Learning order: Movement Fundamentals → Spine/Thorax/Breathing → Pelvis/Hip → Shoulder/Upper Limb → Knee/Ankle/Foot → Integrated Movement/Motor Control.
- Each chapter connects Structure → Function → Movement Analysis → Assessment → Exercise Application → Teaching/Cueing.
- Eight domains: Functional Anatomy/Biomechanics; Assessment; Exercise Library; Cueing/Teaching; Programming/Sequencing; Props/Equipment; Special Populations; Exercise Science/Wellness.
- Muscle records: Origin, Insertion, Primary Action, Secondary Action, Innervation, Functional Role; English first / Korean alongside. Learn by shared bony attachments, line of pull, crossed joints and insertion differences.
- Member assessment and class records in a separate workspace.

## Exercise source fidelity
- Inspect all 186 original photos: 69 Mat/Small Props and 117 Apparatus.
- Record printed heading/page, Why, Starting Position, Breathing/Movement, Watch Points, Variations. Split multi-exercise pages; merge continuation/duplicate exercise records while preserving every source photo.
- Source text and instructor additions visibly separated; do not invent unreadable handwriting or spring values.
- Include muscle action, alignment, hip rotation, knee direction, foot/arch contact, hands, scapula, gaze, cues, compensation, regression/progression.
- Upright photos, zoom, search, apparatus filters, textbook order and mobile readability.

## Practical exam
- 25-minute teaching sequence, then two random movements performed without teaching.
- About 12 counted movements; ≥3 of Mat/Reformer/Cadillac/Chair/Barrel; ≥1 variation; ≥1 small prop.
- Maximum three repetitions TOTAL per movement, including right/left/right or one side three times; do not prescribe 2/side (four total).
- One exercise per series. Preparation/awareness movements not counted.
- Textbook exercises only. Source-check original v12 before revising.
- Two plans: improved user v12 and a distinct recommended plan. Include actual spoken scripts, equipment settings, transitions, easier/harder alternatives, pain response and timing.
- Remove two-hand Circle Mermaid adaptation rejected by user; use a source-grounded prop placement without repeated side changes.
- Shuffle exercise names independently of textbook order; no theory pages, duplicate photos or continuation titles in draw pool.

## Product verification
- Public HTTP success for every linked page; never equate retrieval failure with a proven 404.
- Test mobile layout, navigation/search, random draw, shuffle, state persistence and export/import.
- Fix stale 'future/planned' copy when content exists. Preserve genuine unfinished labels.
- No arbitrary whole-site percent. Every status must name its denominator and evidence.
